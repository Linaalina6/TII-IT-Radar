# TII IT Radar

TII IT Radar — веб-приложение для отслеживания IT-новостей, событий и возможностей.

## Возможности

- Главная панель с обзором IT-событий.
- Каталог новостей по категориям.
- Каталог образовательных и профессиональных возможностей.
- Календарь мероприятий.
- Избранное.
- Административная панель.

## Технологии

- React
- Vite
- Node.js
- Express
- SQLite
