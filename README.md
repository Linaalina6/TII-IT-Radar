# TII IT Radar

Учебный full-stack проект для мониторинга IT-новостей и возможностей. Стек: React + Vite, Node.js + Express, SQLite, RSS Parser, node-cron.

## Требования
- Windows 10/11
- Node.js 20 LTS или новее
- npm

## Запуск
1. Распакуйте архив в удобную папку.
2. Откройте эту папку в VS Code.
3. В терминале выполните `npm install`.
4. Скопируйте `.env.example` в `.env`. При необходимости измените `JWT_SECRET`, логин и пароль администратора.
5. Выполните `npm run dev`.
6. Откройте `http://localhost:5173`.

При первом запуске сервер создаст `server/data/radar.sqlite`, таблицы и демонстрационные данные. База сохраняется между перезапусками.

## Доступ администратора
По умолчанию:
- Логин: `admin`
- Пароль: `admin12345`

Для реального использования обязательно поменяйте пароль и JWT_SECRET в `.env` до первого запуска. Если база уже создана, смена ADMIN_PASSWORD в .env сама по себе не изменит существующий хеш в базе.

## RSS-источники
Войдите как администратор → «Администрирование» → «Добавить» в блоке RSS-источников. Укажите название и прямой URL RSS/Atom-ленты. Кнопка «Запустить сбор RSS» запускает обновление вручную; планировщик по умолчанию проверяет источники каждые 30 минут (переменная RSS_CRON). Дубликаты предотвращаются уникальным URL публикации. Недоступные источники сохраняют текст ошибки в карточке источника.

RSS не гарантирует получение мероприятий с сайтов без открытых лент/API. Такие возможности добавляются администратором вручную. Не все сайты IEEE, ACM, HackerRank, Devpost, Astana Hub и ICPC предоставляют единый публичный RSS/API для всех разделов; наличие конкретного URL необходимо проверить отдельно.

## Что реализовано
- Dashboard, новости, каталог возможностей, календарный список, избранное, дайджест из последних публикаций, персонализация через категории.
- Поиск, фильтры, сортировка, карточки и просмотр материала.
- Авторизация администратора, добавление/удаление новостей и событий.
- Управление RSS-источниками, ручной и периодический сбор, дедупликация, классификация по ключевым словам, обработка ошибок.
- SQLite: Users, News, Categories, Sources, Events, Opportunities, Favorites, Notifications, UserPreferences, Drafts.
- Подготовка черновика из новости: создаётся редактируемая заготовка из исходных полей, это не генерация нейросетью.
- 15 демонстрационных публикаций и 10 демонстрационных событий. Они явно помечены как демо; даты и ссылки не являются реальными предложениями.

## Ограничения текущей учебной версии
- Уведомления и напоминания представлены интерфейсом, но отправка email/push не подключена.
- Персонализация позволяет выбирать категорию и перейти к её материалам; отдельный профиль предпочтений пока не сохраняется.
- Черновики создаются шаблонно без внешней AI-модели. Для реальной AI-генерации потребуется подключить провайдера API и хранить ключ только на сервере в `AI_API_KEY`.
- Календарь пока представлен списком дедлайнов, а не сеткой месяца.
- Админ-редактирование новостей и событий можно расширить; добавление и удаление реализованы.

## Структура
- `client/` — React интерфейс и стили.
- `server/src/db.js` — схема SQLite и seed-данные.
- `server/src/index.js` — REST API, авторизация, RSS и cron.
- `.env.example` — пример переменных окружения.

## Сборка frontend
`npm run build`

Для запуска backend отдельно: `npm start` (после `npm install`).
